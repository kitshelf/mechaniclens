# corpus/ — the research library

This folder is reserved for public research corpora used to calibrate the pattern library. It is not part of the decode and never runs inside a user's screen.

Rules:

- Every dataset is vendored as-is with its license and provenance in a manifest.
- The kit never trains on the corpus. It is a reference for pattern research.
- A candidate pattern enters the rubric only with a source, a *not-a-pattern-when* line, and a fixture that exercises it.
- Never paste corpus material into a user's report.

No datasets are vendored yet. The first release may not need any; the pattern library can be sourced from public repair-industry guidance and fixture work.
