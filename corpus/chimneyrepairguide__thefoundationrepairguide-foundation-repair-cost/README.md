# Foundation Repair Cost Register (U.S., 2026)

Compiled by **The Foundation Repair Guide** (https://thefoundationrepairguide.com/). License: CC BY 4.0 (applies to the compilation; quoted figures remain attributable to their publishers).

80 individual published foundation-repair price ranges from 21 publishers (contractors, contractor networks, cost aggregators, publishers), each with source URL, publisher, the date the source states, the unit, repair type, and the date we re-checked it. Prices are quoted, not estimated; no source pages are reproduced.
