# Worked examples

The kit's calibration story, when written: one estimate that catches a pattern and one clean estimate that must not be over-labeled.

## Planned

| Example | What it shows |
|---|---|
| The catch | A scope mismatch plus fee stacking, labeled and questioned line by line. |
| The not-catch | A clean, well-itemized estimate that gets mostly Standard labels. |

The not-catch is the important one. A decoder that flags every line is not calibrated; the near-miss example is how the kit proves it can leave a clean document alone.

Examples will be recorded from the synthetic fixtures in `../../tests/` and linked here, not copied. Until then, this page is a placeholder.
